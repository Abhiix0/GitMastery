## Quick Start

```bash
git clone https://github.com/YOUR_USERNAME/GitMastery.git
cd GitMastery
```

Pick a module from the [Learning Path](#learning-path) and follow the instructions inside its folder.

---

## Learning Path

Modules are organized into 4 phases — beginner to advanced. Each module follows the same structure:

1. **Guided Lab** — step-by-step walkthrough
2. **Challenge** — do it yourself with hints
3. **Boss Fight** — no hints, real scenario

See [ROADMAP.md](./ROADMAP.md) for the full list of planned modules.

---

## Scenarios

Real-world Git situations you'll actually run into:

- Undoing a bad commit before a push
- Resolving a merge conflict under pressure
- Cleaning up a messy branch history
- Recovering a deleted branch

More scenarios added with each phase.
