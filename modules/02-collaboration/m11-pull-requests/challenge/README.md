# Challenge — m11

Open a PR that adds a **high score** feature to the game.

Requirements:
- Clear, specific PR title
- Description that explains what changed and how to test it
- At least one commit with a meaningful message

Before merging:
- Leave yourself **two code review comments** on the diff
- Address both comments with **follow-up commits** (not by amending)
- Then merge

The review history should show the comments were raised and addressed.
