# Challenge — m09

Push the game to a new GitHub repo.

**Part 1 — clean pull:**
Simulate a teammate making a change. Edit a file directly on GitHub, then pull it locally without conflicts.

**Part 2 — conflict pull:**
Make a local change AND a GitHub change to the **same file** at the same time — different lines or the same line, your choice. Then pull and resolve the conflict. Push the fixed version.

Both parts should end with your local repo and GitHub in sync.
