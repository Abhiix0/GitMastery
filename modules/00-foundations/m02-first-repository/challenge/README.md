# Challenge — m02

Initialize a fresh Git repo — **not** inside `sandbox/`, use a new temp folder somewhere.

Create 3 files, make 3 separate commits, each with a meaningful message. Then use `git log` to prove you did it.

The commits should tell a small story. Someone reading only the commit messages should understand what you built, step by step.

"Add file1", "Add file2", "Add file3" doesn't count.
